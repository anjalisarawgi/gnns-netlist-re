Changelog¶

This project uses semantic versioning. This changelog uses recommended emojis from https://gitmoji.dev/.

0.0.1a24 (2024-05-27)¶

Changed:¶

  • ✨: Add a fuzzy mode to verilog2lib. This mode Searches for partial matches when guessing cell functions based on cell names.

0.0.1a23 (2024-05-03)¶

Changed:¶

  • 👽️: Networkx 3 deprecated gpickle read/write. We have to use our own implementation: https://networkx.org/documentation/stable/release/migration_guide_from_2.x_to_3.0.html#deprecated-code

  • ✅: Add a test for run_hierarchy

  • 🔧: update dockerfile so that tests can be executed

  • 🚑️: run_hierarchy was severely broken, it was producing severely wrong hierarchies due to a missing deepcopy when creating the hierarchy tree

  • 🔇: add a flag to silence warnings about consts used in the netlist.

0.0.1a22 (2023-11-22)¶

Changed:¶

  • 🐛: Revert the removal of the library from cluster2verilog and hierarchy2verilog

    Actually, the library is very much needed, because it gives yosys information on the direction of cell ports. Only with this info, yosys can derive the directions of ports of the extracted module. Without, yosys makes all ports inouts.

0.0.1a21 (2023-11-15)¶

Changed:¶

  • 🐛: Remove the library commandline flag from cluster2verilog

0.0.1a20 (2023-11-15)¶

Changed:¶

  • 🐛: Remove liberty dependency from hierarchy2verilog and cluster2verilog

  • 🐛: Fix yosys script of hierarchy2verilog and cluster2verilog: tcl -> ys script change because of escaping errors

0.0.1a19 (2023-09-26)¶

Changed:¶

  • 📝: Improved docs: Page for cluster2verilog and hierarchy2verilog was missing

  • ✨: Add pickling of parsed verilog to genus2hierarchy, so that rerunning genus2hierarchy on a only changed toml is faster.

0.0.1a18 (2023-09-26)¶

Changed:¶

  • 🐛: In ASIC netlists, it may occur that a node has an unattached output pin (not listed in netlist at all).

    Change parser so that such a cell pin missing is allowed.

  • 🐛: Genus2hierarchy counts unknown module types. however, the +1 was missing.

  • ✨: Add 2 new tools “cluster2verilog” and “hierarchy2verilog” to extract a partition (either detected or original)

    from a verilog netlist in verilog format, so that it can be used with other, maybe external RE-tools.

0.0.1a17 (2023-04-05)¶

Changed:¶

  • 🐛: typo in netlist parsing, nets must be a list-of-dicts, so convert set to list.

  • ✨: Hierarchy parsing now uses regexes, so that hierarchical names separated with `.`s are also OK

0.0.1a16 (2022-10-12)¶

Changed:¶

  • 🔖: version update of synthesis

0.0.1a15 (2022-10-12)¶

Changed:¶

  • 🐛: typo in run_write_adjlist from removing the sia option.

  • 🗑️: deprecate the run_write_adjlist tool, there is a better option: verilog2graph.

0.0.1a14 (2022-10-10)¶

Changed:¶

  • 📝: Improved docs: Page for genus2hierarchy was missing

  • 🐛: Fix a bug when there are INOUTS: this created problems with the duplicate drivers check

  • 🐛: Fix the MANIFEST so that the codegen templates are also provided in the source distribution

  • 🐛: When using verilog2graph, one must use complex output formats with –output_info write_node_type

  • 🐛: During assign handling in parsing, net_drivers shall be updated

  • ✨: space_is_and is now deprecated. The root cause, that is parsing of the boolean functions by

    pyeda, was fixed

0.0.1a13 (2022-07-19)¶

Changed:¶

  • ✨: Add a new tool to generate hierarchies from a general toml file

  • 🎨: Format part of code with black

  • ⚡️: Improve parsing performance with a assign chain cache

  • 🔊: Improve typos and step-information in parsing debug output

  • ✨: Allow inouts, treat them as duplicated inputs and outputs

  • ➕: Add pandas as requirement for parsing

  • 🐛: Fix a severe bug in hierarchy due to bad handling of python objects (sorting objects multiple times into

    a dtastructure requires to copy them!)

  • ✨: Add helpers to find specific constructs in parsed net names

  • ✨: Multidigraph support for commercial libs, where a cell can have multiple outputs that drive the same dependent cell

  • ✨: Handle wires, input and outputs that are buses (multi bit variables)

  • 🐛: When parsing a net name, make sure to search for UNCONNECTED in the whole name

  • ✨: Improve the complete graph with better ff and latch info

  • ✨: Better file logging helper function

  • ✨: Add a config option so that unconnected inputs are kept - this might be needed to go back

    from graph to verilog

  • ✨: In the parsed celllib structure, add more info about ffs, for example the name of

    the internal state variable (this name might be used in pin functions)

  • ✨: Add a new pickle based graph file format

  • 🐛: Fix code generation from AST for escaped verilog identifiers

  • ✨: New interactive cli function to build a cell lib from a unknown verilog (verilog2lib)

  • 📝: Improved docs: Additional parsing code example added

  • 👷: Build docs for merge requests, so that there is feedback for doc updates️

  • 🚑️: Make space_is_and available as a commandline flag in run_hierarchy

  • ✨: allow TESTCELLS in liberty files

0.0.1a12 (2021-11-12)¶

Changed:¶

  • 🐛: Improve Library parsing: Differentiate between library attributes and cell attributes,

    so taht a cell attribute cannot occur as a library attribute

  • 🐛: Ensure uniqueness of driven nodes, else parsing fails for specific nelists.

  • 🔊: Improve error message of a specific parsing error

  • 🐛: Parsing should properly ignore UNCONNECTED nets

  • 🚑️: Hierarchy generation was not using a OrderedDict internally, so the hierarchy was

    evaluated in random order. this lead to not-from-the-bottom-up hierarchy evaluation

  • 🗃️: Sort the columns of the hierarchy output files alphabetically for better readability

  • 🔊: Add some debug status messages

  • 🔇: Allow to mute annoying parser logs run_hierarchy

  • 👷: Release notes now include a link to the changelog

  • ✨: Allow to disable the interrupt disabling in pool_wrapper, because interrupt

    mangling is not allowed in some contexts

  • 🏗️: Fix parquet graph output file format extension

  • 📝: Fix documentation generation

  • 🔖: Ease version bumping

0.0.1a11 (2021-07-08)¶

Changed:¶

  • 📝: Document the parsing of constant inputs

  • 📝: Document the disabling of warnings

  • ✨: New class for easier I/O of netlist graphs

  • 🎨: Lint verilog2fatures

  • 📝: Improve documentation (API order etc.)

0.0.1a7 (2021-04-20)¶

Changed:¶

  • parsing for complete_data also creates inputs for constants

  • change format of graph edge annotations, so that a node driving multiple pins of another node can be represented

  • For old yosys versions, make sure params are not included in hierarchy names

  • For verilog2graph, add a very compact output format based on apache parquet.

  • fix modulename parsing for very contrived name

  • parse bus assignments like assign bus_a[1]=bus_b[1];

  • fix documentation error that linked to the wrong rleases page

  • Fix installation of cli-scripts for the non-editable build

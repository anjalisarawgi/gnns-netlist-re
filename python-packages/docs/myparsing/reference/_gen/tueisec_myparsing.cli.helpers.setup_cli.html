tueisec_myparsing.cli.helpers.setup_cli¶

tueisec_myparsing.cli.helpers.setup_cli(log_level='debug', file_logging=False, additional_loggers=None, log_config={'datefmt': '%Y-%m-%d %H:%M:%S', 'fmt': '{levelname}: - {asctime} - [{name}] - {message}', 'style': '{'}, file_logging_path='all.log')[source]¶

setup logging for cli

recommended parser config is:

setup argparse¶
parser.add_argument(
    "--logger",
    "-l",
    help="logger level. Default: info",
    choices=["info", "debug", "warning", "error", "critical"],
    default="info",
)
Parameters:

  • log_level (str, optional) – loglevel, as returned by recommended argparser, defaults to “debug”

  • file_logging (bool, optional) – if file logging shall be enabled, defaults to False

  • additional_loggers (iterable, optional) – provide an iterable of additional logger names to set the logging level for, defaults to None

  • log_config (bool, optional) –

    config dict for logging, input with **log_config to logging.Formatter, defaults to

    default formatting config¶
    log_config = {
    "fmt": "{levelname}: - {asctime} - [{name}] - {message}",
    "style": "{",
    "datefmt": "%Y-%m-%d %H:%M:%S"
}

  • file_logging_path (str, optional) – if file logging is enabled, log to this path.

Raises:

ValueError – ValueError if the provided log_level is unknown.

tueisec_myparsing.liberty_parsing.parse_cell_function¶

tueisec_myparsing.liberty_parsing.parse_cell_function(function, library_name, space_is_and=None, exprvar=False)[source]¶

Normalize the cell functions.

If the library uses space as and, parse all spaces to ampersand chars. If the space surrounds a plus sign (as with the osu035 lib), so not replace it.

Parameters:

function (str) – The function string as provided by the library

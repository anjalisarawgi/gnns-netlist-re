tueisec_myparsing.parsed_verilog_ply.ParsedVerilog¶

class tueisec_myparsing.parsed_verilog_ply.ParsedVerilog(netlist_file, cell_lib, debug_ply=False, add_const_as_input=False, show_all_const_warnings=False, delete_unconnected_inputs=True)[source]¶

Object representing a verilog file.

Variables:

  • module_name – Name of the parsed module

  • nets – Dict containing a list of driven nodes for each net: ["net_a": ["AND2X1", "DFFPOSX1" ...], "net_b": ...]

  • nets_to_nodes – Dict mapping net names to the net driver, generated at end.

  • netlist_file_path – Path of the parsed file

  • cell_lib – cell_lib object corresponding to this netlist

  • nodes –

    Tuple of node information: (in_nodes, nodes, out_nodes), where each is a list of nodes. each node is a dict of:

    inst_name: {
    "cell_type": cell_name,
    "dest": node_dest,
    "src": node_src
}

    and dest and src are lists of pin tuples like:

    (pin_name, net_name)

  • node_types – Simplified nodes dict only containing node-to-cell_type mapping

  • graph – Netlist graph as a dictionary adjacency list. For each node, there is a list of destination nodes.

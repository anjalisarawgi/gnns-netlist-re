tueisec_myparsing.myparsing.parse_to_obj¶

tueisec_myparsing.myparsing.parse_to_obj(netlist_file, liberty_file, pickle_folder='/home/johanna/work/git/RE/tum_re_parsing', exprvar=False, space_is_and=None)[source]¶

Main entry point for parsing a verilog file using a refined API.

Specify the verilog file to parse and the liberty file to use.

Parameters:

  • netlist_file (str) – Filepath of the verilog file to parse

  • liberty_file (str) – Filepath of the liberty file to use

  • pickle_folder ([type], str) – Folderpath, where the parsed liberty file can be found, defaults to os.getcwd()

  • exprvar (bool, optional) – If set to true, cell functions are returned as pyeda expressions, defaults to False

  • space_is_and (bool, optional) – Deprecated option kept for compatibility. Do not use. Defaults to None.

Returns:

Returns a ParsedVerilog object.

Return type:

tuple

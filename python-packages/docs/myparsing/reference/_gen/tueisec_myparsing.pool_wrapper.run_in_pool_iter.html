tueisec_myparsing.pool_wrapper.run_in_pool_iter¶

tueisec_myparsing.pool_wrapper.run_in_pool_iter(loop_function, loop_parameters, processes=7, abort_on_kint=True, initializer=None, initargs=(), no_signal_mod=False)[source]¶

Run a loop function on a process pool with given input data and return an interator.

This helper function initializes a multiprocessing pool, catches the Keyboard interrupt so that the runners are terminated as well, and breaks everything down on completion.

This function returns an iterator that yields the return values of the loop function.

Parameters:

  • loop_function (Callable[[tuple[Any]], Any]) – Function to loop through via multiprocessing. shall accept one single parameter: a tuple that contains all loop-step parameters

  • loop_parameters (list[tuple[Any]]) – List of function parameters as tuples. each call to loop_function receives one element of this list.

  • processes (int, optional) – Number of processes, i.e. the number of workers, to start with multiprocessing, defaults to 7. If None is given, all CPUs-1 will be used.

  • abort_on_kint (bool, optional) – Specify if on Ctrl+C, this function throws a KeyboardInterrupt, or catches it and only aborts the loop, defaults to True

  • initializer (Callable[[Any, ...], None], optional) – function to be executed once at the initialization of the worker processes. Especially, this can be used to init global variables per worker process, that are then accessed in the loop_function each time, but only needs to be transferred to the worker one, at the init. defaults to None

  • initargs (tuple[Any], optional) – Tuple of arguments to the initializer function, the tuple will be unpacked and given param by param to the initializer function, defaults to None

Raises:

KeyboardInterrupt – This function raises an KeyboardInterrupt exception only if abort_on_kiint is True and Ctrl+C is pressed.

Returns:

This function returns an Iterator that yields the return values of the loop_function unordered.

Return type:

iterator

tueisec_myparsing.parsed_verilog_ply.ParsedVerilog.__init__¶

ParsedVerilog.__init__(netlist_file, cell_lib, debug_ply=False, add_const_as_input=False, show_all_const_warnings=False, delete_unconnected_inputs=True)[source]¶

Initialize the ParsedVerilog by parsing a source file

Parameters:

  • netlist_file (str) – Path to a verilog file

  • cell_lib (object) – parsed cell library

  • debug_ply (bool, optional) – Enable debug output from ply parsing, defaults to False

  • show_all_const_warnings (bool, optional, default=false) – Enable all warnings for constants which are not added as an input

  • add_const_as_input (bool, optional) –

    If enabled, phantom inputs INPUT_CONSTANT_0 and INPUT_CONSTANT_1 will be added to the netlist inputs. Any 1-bit constants in standard cell ports or in rhs of assign statements will be replaced by the respective phantom input, so that an additional wire goes from the input to the standard cell or assignment lhs. Defaults to False, which triggers warnings if constant assignments are found. You can hide these warnings with a logging.Filter, see Usage.

    Note

    CLI: At the moment, this is only supported in the cli tool verilog2graph, if you specify --output_info complete_data.

  • delete_unconnected_inputs – If enabled, any inputs that are not connected to a cell will be deleted, i.e. even the INPUT_ dummy cell is thrown away.

Returns:

A new ParsedVerilog object

Changelog¶

This project uses semantic versioning. This changelog uses recommended emojis from https://gitmoji.dev/

0.0.1a21 (2024-03-05)¶

Changed:¶

  • 🐛: Fix a inconsistency between ig’s and nx’s closeness centrality. it must be 0 for INPUTs

  • ✨: When converting from nx2igraph, use ig’s own conversion function

0.0.1a20 (2024-03-03)¶

Changed:¶

  • 🐛: Fix a incompatibility with newer versions of networkx

0.0.1a19 (2024-02-07)¶

Changed:¶

  • 🐛: Fix a bug in printing of overlong wires, there were no linebreaks

0.0.1a18 (2024-01-15)¶

Changed:¶

  • 🐛/✨: allow very long module names in netlists

0.0.1a17 (2023-08-09)¶

Changed:¶

  • ✨: new tool to convert the output of clustering to a representation nice for gephi

0.0.1a16 (2023-04-26)¶

Changed:¶

  • 🐛️: Fix folder hierarchy of new clustering output: every algo should have at least one parameter, so that all algos have a hierarchy level defining the params

0.0.1a15 (2023-02-13)¶

Changed:¶

  • ✏️: typo in setup.py - wrong package name for scikit-learn

0.0.1a14 (2023-02-13)¶

Changed:¶

  • ⬆️: now depending on python 3.8, as should have always been the case since commit 60102213e896006f941508b9298226ae812d414c

  • ➖: remove dependency on sklearn and…

  • ➕: add dependeny on scikit-learn, which is the canonical, nondeprecated name

  • ✨: new tool to calculate hasegawa features in the netlist

0.0.1a13 (2022-07-19)¶

Changed:¶

  • ⚡: Clustering: overwrite logic adapted accordingly

  • ✨: Clustering: new output implementation:

    Output folder names use individual IDs instead of parameter values. Parameters are saved into a toml file, separately.

  • 🏛️ : Keep legacy clustering datastructure below –legacy flag

0.0.1a12 (2022-07-15)¶

Changed:¶

  • 👷: Have newlines in the release description…

  • 📝: Document the usage of clustering config roughly

  • 📦: Use sklearn as a requirement…

0.0.1a11 (2022-07-15)¶

Changed:¶

  • 📝: Document how to release a new version in Contributing

  • 📦️: Cleanup of setup.py, python requirements etc.

  • 📝: MCL documented in installation instructions

  • 👷: Maybe fix the release script once and for all.

  • 📝: Improved docs: Additional code example added

  • ✨: In make_features you can now pass a single file on the commandline and it will be handled!

  • 🐛: It is mandatory to give an output path. this is now enforced by the argumentparser

  • ✨: Requirement for graphtool reduced: there is a fast calculation that is solely based on igraph and networkx now.

    Use –use_ig as a flag for make_features

  • ➕: New networkx versions have another internal api we depend on, as we modify an networkx method for our purposes.

    We need to update the requirements for python packages.

  • ✨: There is a very rough version of a hasegawa-feature (HT detection) calculator now.

  • 👷: CI should build docs also for merge requests => you can see what you do when updating docs in MRs

  • 📝: Broken link in docs fixed

0.0.1a10 (2022-01-07)¶

Changed:¶

  • 🐛: Fix input/output analysis for split_ports

  • ⚡: Add feature to run clustering without hierarchy files

0.0.1a9 (2021-10-21)¶

Changed:¶

  • ⬇️: Limit versions of python-igraph and leidenalg

  • 📝: Make docs building again

  • 🥅: Catch more errors during eigenvector centrality calculation

  • 🥅: Ignore bad parquet files in feature calculation

  • ✨: Add unflattened version of louvain_dend and nsbm via a config flag in the clustering_params.toml

  • ⚡️: remove exceptions-used-for-branching in louvain calculation

  • ✨: In clustering, import graph_tool as late as possible, i.e. only if nsbm is acutally used.

0.0.1a8 (2021-07-31)¶

Changed:¶

  • ✨: Introduce make_scoap to calculate scoap data for a design

  • 👷: fix CI release message with proper linebreaks

0.0.1a7 (2021-07-12)¶

Changed:¶

  • 👷: improve CI release message with a changelog

  • 📝: make_features only accepts folders for now.

  • 🐛: fix error reporting for empty input folders to make_features

  • 🐛: make a list of the known formats in make_features, because else the tool only accepts one input folder.

  • 🐛: In make_features, try to get rid of some unnecessary copies.

0.0.1a6 (2021-07-12)¶

Changed:¶

  • 📝: Improve documentation of make_features, run_make_csv, run_csv_to_hdf5

  • 🎨: lint make_features

  • 👷: update release script so that it generates non-404ing links

  • 🐛: fix graph_tests_nx, there was a bad parameter name and wrong string formatting in loggin

  • ✨: Import graph_tool as late as possible, so that the usage of --use_nx is possible without having graph_tool installed.

0.0.1a5 (2021-07-07)¶

Changed:¶

  • 🐛: Wrong requirements for igraph fixed.

  • 🐛: In feature calculation, if the node type is None, do not crash.

  • ✨: Add a new tool (executable make_features) for feature generation.

  • 🗑️: Deprecate run_make_csv in favor of make_features.

0.0.1a4 (2021-05-28)¶

Changed:¶

  • 🐛: Match exporting returned wrong type on empty match

  • 🐛: Walksacan must not accept an float as nb_steps

  • 🐛: louvain_dend returned wrong type

  • 🐛: wrong variable name in louvain clustering

  • 🐛: Missing requirements and imports

  • 🐛: Workaround for Gitlab Bug in publishing

0.0.1a3 (2021-05-04)¶

re_verilog2features.create_data¶

Feature extraction functions, to be used with read_adjlist_and_make_csv.py

CAREFUL: If you do not want OPENBLAS / ARPACK to use all cores of the host system, use this line BEFORE importing this or any of nx, np, scipy, pandas etc.!

os.environ["OPENBLAS_NUM_THREADS"] = str(<number_of_cores>)

Also be careful because this parameter is threads per python process, so if you use multiprocessing, consider that #total_treads = #multiprocessing_pools * OPENBLAS_NUM_THREADS
